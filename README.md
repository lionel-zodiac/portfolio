## Getting started (local)
Option A — Open directly
1. Clone the repo
   ```
   git clone https://github.com/codewith-lionel/portfolio.git
   ```
2. Open the site
   - Open `index.html` in your browser.

Option B — Use a simple static server (recommended for routing or AJAX)
1. Using Node (npx serve)
   ```
   npx serve .
   ```
2. Using Python (built-in)
   - Python 3:
     ```
     python -m http.server 3000
     ```
   - Then open `http://localhost:3000` in your browser.
